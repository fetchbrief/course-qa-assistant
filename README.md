# 课程智答助手 · Course QA Assistant

一个基于 **RAG（检索增强生成）** 的课程问答服务。
用向量检索从平台文档里找出最相关的内容，**低于相似度阈值时主动拒答**；
检索之后再把资料交给模型生成回答，**并强制它「资料里没有就说不知道」**。

---

## 解决什么问题

在线教育平台的客服要反复回答同一批基础问题（退费政策、证书领取、直播规则）。
通用大模型**不了解平台自己的制度文档** —— 直接问它会编造政策。

实测（不给文档，直接问模型）：

| 问题 | 真实答案 | 直接问模型 |
|---|---|---|
| 退费几天内可全额退款？ | 7 个自然日 | 「无法确认具体天数」 |
| 作业逾期扣多少分？ | 20% | 「通常没有统一标准」 |

**→ 模型的训练数据里没有你公司的规则。不检索，就只能回答「不知道」或者瞎猜。**

这个服务的做法是：

1. **只依据给定文档回答**，并返回来源（哪篇文档、哪一段、相似度多少）
2. **检索分数不够 → 直接拒答**，不猜、不编
3. **检索到了但资料里没有答案 → Prompt 约束模型说「不知道」**

## 怎么跑

```bash
# 1. 建环境（Python 3.10）
uv venv --python 3.10 .venv
uv pip install --python .venv/Scripts/python.exe -r requirements.txt

# 2. 起服务
.venv/Scripts/python.exe app.py --host 0.0.0.0 --port 8000

# 3. 试一下
curl http://127.0.0.1:8000/health
curl http://127.0.0.1:8000/config
```

浏览器打开 `http://127.0.0.1:8000/` 有个提问页面。

> ⚠️ Windows 上用 curl 发中文会乱码（终端编码问题），把请求体写进文件再用 `--data-binary @q.json`。

### 切换生成后端

```yaml
# config/generation.yaml
backend: mock        # 不联网，本地测试用，零成本
# backend: anthropic # 调真实模型（需要环境变量 ANTHROPIC_API_KEY）
```

## 接口

| 接口 | 说明 |
|---|---|
| `GET /health` | 健康检查：模型/索引状态、生成后端、缓存命中统计 |
| `GET /config` | **返回当前生效的配置** —— 排查「改了配置没生效」 |
| `POST /answer` | 单条问答 |
| `POST /batch_answer` | 批量问答（1–10 条，结果顺序与输入一致） |
| `POST /cache/clear` | 清空问答缓存（知识库更新后调用） |
| `GET /` | 极简 Web 页面 |

**请求：**

```json
{"question": "我要退钱", "top_k": 3, "request_id": "req_0001"}
```

**响应：**

```json
{
  "request_id": "req_0001",
  "answer": "开课后 7 个自然日内、学习进度未超过 10% 的，可以申请全额退款。【来源1】",
  "intent": "course_query",
  "sources": [{"id": "学员手册", "title": "学员手册 · ## 五、退费政策", "score": 0.5577}],
  "confidence": 0.5,
  "is_refused": false,
  "latency_ms": 3
}
```

## 关键设计

### 1. 检索六步

```
问题 → ① 转向量 → ② 逐段算余弦 → ③ 过阈值 → ④ 排序 → ⑤ 按文档去重 → ⑥ 取前 top_k
```

- **只有第 ① 步用到模型**（小的 embedding 模型，本地跑）
- **②–⑥ 全是算术**，耗时 < 1 ms

### 2. 文档分块（chunking）

长文档整篇向量化会**稀释掉细节** —— 整本手册的向量是「全篇平均意思」。
所以按 `##` 小标题切段，超过 400 字再硬切，相邻段重叠 80 字（避免把话劈断）。

**实测收益：**

| 问题 | 整篇 | 切分后 | 提升 |
|---|---|---|---|
| 直播断线了怎么办？ | 0.5333 | **0.6630** | **+0.13** |
| 作业迟交会扣分吗？ | 0.5124 | **0.6530** | **+0.14** |
| 账号可以借给同学吗？ | 0.4737 | **0.5825** | **+0.11** |
| 可以申请开发票吗？（无答案） | 0.4953 | 0.4953 | **0** |

→ **切分只推高「有答案」的问题，推不动「没答案」的问题。**

### 3. 用余弦相似度，不用欧氏距离

同一句话写成 3 个字和 30 个字，**向量长度差很多，但方向几乎一样**。
比距离会被长度带偏，比方向不会。

### 4. 三层防幻觉

| 层 | 手段 | 挡什么 |
|---|---|---|
| 1 | 阈值拒答 | 完全无关的问题 |
| 2 | Prompt 约束（`prompts/system.txt`） | 语义相近但**没有答案**的问题 |
| 3 | 来源编号 | 编造的回答没处可引 |

**实测「学费能分期付款吗？」：**

- 检索到 2 段退费政策，分数 0.5687 / 0.5637（**都高于阈值 0.45，第 1 层没挡住**）
- 模型回答：「这个问题超出了本站课程咨询范围。提供的文档仅涉及退费政策，未包含学费分期付款的相关内容。」

→ **第 2 层挡住了。这就是为什么阈值不能解决所有问题。**

### 5. 缓存

测出来瓶颈不在检索（<1 ms），而在模型调用（500–1200 ms）。
所以优化方向是**少调模型**：同一问题命中缓存后 **1209 ms → 0 ms**。

- TTL 300 秒自动过期（政策改了不能一直给旧答案）
- `POST /cache/clear` 手动清空
- **失败结果不缓存**

### 6. 配置与代码分离

所有参数在 `config/*.yaml`，代码里不写死。
配置文件缺失时**打警告 + 用默认值**，不崩溃。
`GET /config` 能直接看到代码读到了什么。

## 实测效果

| 用户问法 | 命中 | 相似度 |
|---|---|---|
| 直播断线了怎么办？ | 学员手册 · 二、直播课与回放 | **0.6630** |
| 作业迟交会扣分吗？ | 学员手册 · 三、作业与测验 | **0.6530** |
| 账号可以借给同学吗？ | 学员手册 · 六、账号与安全 | **0.5825** |
| 学费能分期付款吗？ | 命中但无答案 → **Prompt 层拒答** | 0.5687 |
| 今天天气怎么样？ | **拒答**（低于阈值） | 0.3033 |

**同义改写能力：**

| 对比 | 余弦 |
|---|---|
| 「我要退钱」vs「申请全额退款」 | **0.7486** |
| 「我要退钱」vs「今天天气怎么样」 | 0.3496 |

> 「退钱」和「退款」**没有一个字相同**，但向量认得出它们是同一个意思。

## 技术栈

`Python 3.10` · `FastAPI` · `Pydantic` · `fastembed`（ONNX 推理，不依赖 PyTorch）
· `bge-small-zh-v1.5`（512 维中文嵌入）· `httpx`（调模型接口）· `PyYAML`

**为什么用 fastembed 而不是 sentence-transformers**：ONNX 推理，不需要装 PyTorch，
在 CPU 机器上体积和启动开销都小得多 —— 这个项目的部署环境没有 GPU。

---

## 已知限制

- **文档量小**（3 篇 / 9 段）。文档到几千篇以上时，需要引入 **FAISS** 等向量索引，而不是逐个算余弦。
- **去重按文档 id 做，比较粗** —— 同一篇文档里的第二段有用信息会被砍掉。更好的做法是按内容相似度去重。
- **阈值 0.45 是用少量样例调的**，样本不足，换数据集需要重新标定。
- **缓存 TTL 固定 300 秒**，没有做「知识库变更 → 自动失效」。
- **生成后端为 mock 时**，回答只是模板拼接，不代表最终效果。
