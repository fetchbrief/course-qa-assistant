# 课程智答助手 · Course QA Assistant

一个基于 **RAG（检索增强生成）** 的课程问答服务。
用向量检索从课程文档里找出最相关的内容，**低于相似度阈值时主动拒答**，不给没有依据的答案。

---

## 解决什么问题

在线教育平台的客服要反复回答同一批基础问题（退费政策、证书领取、直播时间）。
通用大模型**不了解平台自己的制度文档** —— 直接问它会**编造政策**。

这个服务的做法是：

1. **只依据给定文档回答**，并返回来源（哪篇文档、相似度多少）
2. **文档里没有的，直接拒答** —— 不猜、不编

---

## 怎么跑

```bash
# 1. 建环境（Python 3.10）
uv venv --python 3.10 .venv
uv pip install --python .venv/Scripts/python.exe -r requirements.txt

# 2. 起服务
.venv/Scripts/python.exe app.py --host 0.0.0.0 --port 8000

# 3. 试一下
curl http://127.0.0.1:8000/health
```

浏览器打开 `http://127.0.0.1:8000/` 有个提问页面。

> ⚠️ Windows 上用 curl 发中文会乱码（终端编码问题），把请求体写进文件再用 `--data-binary @q.json`。

## 接口

| 接口 | 说明 |
|---|---|
| `GET /health` | 健康检查，返回模型/索引加载状态 |
| `POST /answer` | 单条问答 |
| `POST /batch_answer` | 批量问答（1–10 条，结果顺序与输入一致） |
| `GET /` | 极简 Web 页面 |

**请求：**

```json
{"question": "我要退钱", "top_k": 3, "request_id": "req_0001"}
```

**响应：**

```json
{
  "request_id": "req_0001",
  "answer": "...",
  "intent": "course_query",
  "sources": [{"id": "refund_policy", "title": "退费政策", "score": 0.662}],
  "confidence": 0.662,
  "is_refused": false,
  "latency_ms": 12
}
```

## 关键设计

### 1. 文档向量只算一次

启动时把所有文档各算一次向量存进内存，**每次请求只算「问题」这一个向量**。
现算文档向量会慢一个数量级。

### 2. 用余弦相似度，不用欧氏距离

同一句话写成 3 个字和 30 个字，**向量的「长度」会差很多，但方向几乎一样**。
比距离会被长度带偏，比方向不会。

### 3. 阈值拒答

```
最高相似度 < 阈值  →  拒答（sources 为空，is_refused = true）
最高相似度 ≥ 阈值  →  正常回答
```

**阈值是全局固定的一个数**，不是按当前最高分现调 —— 否则永远会答，拒答功能失效。

## 实测效果

| 用户问法 | 命中文档 | 相似度 |
|---|---|---|
| 「我要退钱」 | 退费政策 | **0.662** |
| 「我想退钱」 | 退费政策 | 0.546 |
| 「怎么拿结业证书」 | 结业证书 | **0.791** |
| 「结业证咋领」 | 结业证书 | 0.642 |
| 「今天天气怎么样」 | **拒答** | 0.323（低于阈值 0.45） |

> 注意前两行：**问句和文档里没有一个相同的二字词，照样能匹配上** ——
> 这是向量检索相对关键词匹配的核心优势（旧版用"数字面"的做法在这里只能拿到 1 分，两篇文档打平）。

## 技术栈

`Python 3.10` · `FastAPI` · `Pydantic` · `fastembed`（ONNX 推理，不依赖 PyTorch）
· `bge-small-zh-v1.5`（512 维中文嵌入）

**为什么用 fastembed 而不是 sentence-transformers**：ONNX 推理，不需要装 PyTorch，
在 CPU 机器上体积和启动开销都小得多 —— 这个项目的部署环境没有 GPU。

---

## 已知限制

- **文档量小**（2 篇）。文档到几千篇以上时，需要引入 **FAISS** 等向量索引，而不是逐个算余弦。
- **只做了检索，没接生成模型** —— `answer` 字段目前是模板拼接，不是真正的大模型生成。
- **阈值 0.45 是用少量样例调的**，样本不足，换数据集需要重新标定。
- 文档切分是整篇入库，**没做分块** —— 长文档会稀释相关性。
